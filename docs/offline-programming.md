# 离线源码编辑

程序页提供“示教”和“代码”两种工作方式。示教点保存关节与工具姿态快照，用现有运动规划器运行；代码页保存用户编写的厂商语言源码。两者不会在后台自动互相覆盖。点击“从示教生成”才将当前示教程序写入所选源文件，并可撤销。

## 编辑与文件

- 按机器人型号隔离源码工程。同品牌不同型号也有独立文件和草稿，切换型号不会把另一机器人的点或代码带入。
- 本地打包 CodeMirror，提供词法高亮、语法诊断、补全、参数与悬停说明、指令参考、折叠、查找、撤销和重做。无需联网下载语言服务。
- ABB 可选择 RobotWare 6.16 或 7.21，RW7 新建默认采用 `.modx`／`.sysx` 的 UTF-8 模块格式；FANUC 使用 R-30iB TP/LS，安川使用 YRC1000 INFORM。具体手册版本与覆盖情况见下表。
- 代码页“插入当前姿态”在当前例程／运动区插入品牌指令，同时建立唯一位置记录。ABB 保留四元数和 robconf，FANUC 写关节位置，安川写 BASE/RECTAN 笛卡尔位置。工具、用户坐标和厂商配置尚未标定的字段保留占位并显示诊断，不凭空生成控制器参数。
- 原生客户端以系统文件窗口导入／导出源码；浏览器提供文件选择与下载。支持 UTF-8 文本，保留 BOM 和原有换行，不把未知语法删除或转换成空指令。二进制 TP、加密模块和其他编码需要先由对应工具转换成明文源码。
- 每个源文件上限 1 MiB，每个工程最多 32 个文件、当前源码总计 4 MiB。文件名必须符合当前语言扩展名及跨平台规则。同名导入会明确拒绝，不覆盖已有文件。

RobotWare 7 的 `.modx`／`.sysx` 是 UTF-8 纯文本，厂商要求无 BOM。导入含 BOM 的现代模块会提示格式问题，保存仍保留用户原文；不会偷偷删除字符或改扩展名。旧 `.mod`／`.sys` 使用不同的编码约定，面向 RW7 的 UTF-8 非 ASCII 内容应另存为现代模块格式；RW6 仍须使用其支持的旧格式和编码。此工具不自动把源文件转成 ISO-8859-1 或 Shift-JIS。

自动草稿存入本机 IndexedDB。“草稿已保存”只表示应用内恢复副本；文件的未保存标记表示它与最近实际导出版本不同。浏览器只能确认下载请求发出，不能确认用户保存位置，因此不会把下载请求冒充磁盘保存成功。原生保存只在文件写入成功后更新基线。存储失败时保留内存中的修改并提示重试；正常关闭等待未完成草稿，强制终止进程不保证最后一次编辑已经落盘。

KRL 已有实验性编辑语言模块，尚无可选 KUKA 型号，也不宣称完整 KSS 支持；见[边界说明](../vendor/robot-languages/krl/README.md)。FANUC KAREL 是另一种语言，不属于 TP/LS。厂商选件、用户库和新控制器版本不能仅靠识别关键词就算完成适配；逐项差异保留在对应语言文档中。

语法诊断在独立本地 Worker 运行，以型号、语言版本及源码修订号隔离结果。更改文件后立即撤下旧诊断，取消过时任务；超时或线程失败显示未完成检查，不显示“无错误”来代替失败。语言资料随应用打包，指令文档链接只在用户主动访问时打开。

## 运行与控制器交付

代码页目前提供源码编辑和静态语法检查，尚无任意 RAPID／TP／INFORM 程序解释器，因此代码运行按钮明确不可用。修改代码后不会运行旧示教点。现有“示教”页仍能规划全部运动段并驱动三维仿真，支持闭合段验证及循环播放。

导出源码保存的是用户的原文，不代表通过控制器编译、选件、工具标定、I/O 配置、运动可达或实机验证。已有 ABB 单段原生导出保持独立入口和 Rust 复验。这些能力与语法完整性分开记录：缺少解释器不是遗漏语法产生式的理由，语法检查通过也不是控制器执行证明。

## 开发边界

`src/programming/` 包含版本注册、文档存储、编辑器、Worker 协议、各语言分析与源码文件桥接。`src/workspace/` 保持示教程序与仿真协作。数值运动继续走 Rust，语法线程不替代原生求解。

新增语言必须声明控制器与参考版本、逐类合法和最小非法示例、词法规则及覆盖缺项；新增型号显式映射语言，不用品牌名称推断未实现支持。保持源码位置为 UTF-16 索引，编辑器负责原始 CRLF／BOM 与显示偏移映射。厂商手册仅作核对，不在客户端重新分发其 PDF 或复制说明正文；引用数据及第三方许可证在 `vendor/robot-languages/`，生产包包含相应声明。
